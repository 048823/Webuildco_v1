How to automate admin work in Australia: a triage method, not a tool list

Most automation advice hands you a tool. This hands you a sorting method — the three-question test that tells you which admin tasks are worth automating, in what order, and which to leave with a human.

Johan Iskandar · 20 July 2026

To automate admin work in Australia, don't start with a tool — start by sorting the work. The method is a triage: list every recurring admin task, score each against three tests (is the input readable, are the rules statable, is the action loggable), automate the tasks that pass all three, and leave the rest with a human. Tool selection comes last, and for most SMBs it barely matters.

The reason to lead with triage is that the expensive mistakes happen the other way round: a business buys a shiny platform, then bends its work to fit it. Six months later the subscription is running and the admin pile hasn't moved. Sort first, buy last.

Step 1: write the whole list, not the annoying bits

Spend twenty minutes writing down every task that repeats — daily, weekly, monthly. Inbox replies, quote follow-ups, invoice chasing, appointment reminders, data entry between two systems, report assembly, intake forms. Include the small stuff. The tasks that feel too minor to mention are often the ones that eat an hour a day in five-minute slices.

Step 2: score each task on three questions

Every task gets three yes/no answers. Is the input readable? — does the work arrive as text, a form, an email, or a call that can be transcribed, rather than a judgement in someone's head. Are the rules statable? — could you write the decision as an if-this-then-that a new hire could follow. Is the action loggable? — does the task end in a concrete action (send, book, file, update) you could check afterward. Three yeses and real volume: automation candidate. Any no: it stays human, and no honest agency will tell you otherwise. The full version of this test is the agent-readiness checklist.

Step 3: rank the candidates by payback, not by pain

The task that annoys you most is not always the one to automate first. Rank the survivors by volume × loaded cost of the time. A five-minute task done eighty times a week beats a one-hour task done fortnightly. Market framing, not a performance claim: if a task consumes a day a week of admin time, that slice is worth roughly A$17,000–23,000 a year in loaded wages (market figures — check current award rates for your state). That number is the budget you're freeing, and the honest denominator for whether a build is worth it.

Step 4: automate the top one, supervised, before touching the rest

Automate the single highest-payback task first and run it supervised — the agent drafts, a human approves, autonomy is earned once the logs prove it. Don't automate five things at once; you won't be able to tell which one broke. Once the first workflow has earned trust, move down the ranked list. This is also where owning the build matters: rented 'AI employee' subscriptions leave the workflow behind when you leave the platform, whereas an owned agent runs in your own accounts — the trade-off is laid out in the cost comparison against hiring.
