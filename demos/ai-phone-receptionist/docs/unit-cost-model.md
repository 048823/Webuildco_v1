# Unit Cost Model

Date checked: 2026-08-03

Recommended stack: Twilio AU local inbound number + Twilio Media Streams + OpenAI Realtime `gpt-realtime-2.1-mini` + Twilio SMS summary.

Currency: source prices are USD unless noted. AUD conversion uses `1 USD = 1.54 AUD` as a working estimate only.

## Assumptions

| Input | Value |
| --- | ---: |
| Average call length | 3.5 minutes |
| Twilio AU local number | USD 3.00/month |
| Twilio AU local inbound call | USD 0.0100/min |
| Twilio Media Streams | USD 0.0044/min |
| OpenAI Realtime mini budget | USD 0.0350/min |
| Twilio AU outbound SMS summary | USD 0.0515/call |
| Email summary | USD 0.00/call |
| Extra platform fee | USD 0.00 |

OpenAI publishes Realtime pricing by audio/text token, not by connected call minute. The `USD 0.035/min` line is a conservative feasibility budget for `gpt-realtime-2.1-mini` that allows for speech token variation, short tool responses, prompt overhead, and testing headroom. Replace it with actual OpenAI usage after the first live 30-call test set.

Call recording is not included because the recommended demo leaves recording off by default. If enabled, add Twilio recording at USD 0.0025/min plus storage at USD 0.0005/min/month, and only after the consent flow is legally approved.

## Margin Reality

If the service is sold at A$500/month:

| Calls/month | Infra AUD | Gross before labour | Max support hours at A$100/h before margin hits zero |
| ---: | ---: | ---: | ---: |
| 50 | 21.90 | 478.10 | 4.8 |
| 200 | 73.74 | 426.26 | 4.3 |
| 500 | 177.41 | 322.59 | 3.2 |

Conclusion: infrastructure cost is not the margin killer. Human operational load is. A A$500/month offer works only if ongoing support averages below roughly 2-3 hours/client/month, or usage is capped with overage pricing.

## Recommended Commercial Guardrail

For pilots:

- Setup fee once custom integrations begin.
- Monthly base includes a stated call-minute allowance.
- Overage priced per connected minute, not "unlimited".
- First 14 days or first 50 calls are supervised.
- Clear exclusion for emergency, legal, medical, financial, and unsupported trade advice.
